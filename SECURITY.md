# Security policy

Do not include credentials, access tokens, Dataverse URLs containing sensitive
identifiers, customer data, production telemetry keys, or private environment
configuration in issues or pull requests.

For a vulnerability introduced by this Codex adaptation, report it privately to
the repository owner after the repository has been published.

For vulnerabilities inherited from the Microsoft upstream project, follow the
security policy at:

https://github.com/microsoft/power-platform-skills/security/policy

Do not create a public issue for an unpatched vulnerability.
